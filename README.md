## 1. Portfolio Overview

This portfolio showcases the physical objects, parametric 3D CAD assemblies, workshop prototypes, and ergonomic systems engineered by **Thanush Puvanesvaran**. 

Rooted in the disciplined, Swiss-minimalist presentation methodology inspired by **Dominik Scherrer** (*Behance Industrial Product Design Portfolio 2023*), the portfolio pairs tangible workbench craftsmanship (FDM 3D printing, foam sculpting, timber joinery, material CMF) with parametric digital engineering (Autodesk Fusion 360, KeyShot, AutoCAD).

### Core Highlights
- **Dedicated First-Row Designer Introduction**: Prominent, high-resolution portrait showcase (`460px × 580px`) with an interactive switcher between **Studio Portrait** (`thanush_proffesional.png`) and **Formal Executive Portrait** (`formal_me.jpg`).
- **Interactive 3D CAD Modeling Studio**: Real-time Three.js viewport showcasing the **Agomoto Acoustic Speaker** assembly with 360° orbit controls, 3 shading modes (*Shaded CMF*, *Technical Wireframe*, *Clay Studio*), turntable auto-rotation, and an interactive **0%–100% Exploded View Slider** that separates all 6 CAD multi-body components in 3D space.
- **Floating Architectural Console Dock**: A floating navigation capsule featuring a custom **Industrial Design Geometric CAD Emblem (SVG)** combining an isometric solid cube, drafting caliper dimension ring, and 3-axis coordinate vectors.
- **Classical Atelier & Museum White Theme**: Multi-stop warm alabaster gradient background layered with **Generative CAD Aerodynamic Streamlines**, an **Interactive Cursor Spotlight Follower** that illuminates the 36px architectural drafting dot grid, and floating corner crosshairs.
- **Persistent Dual Mode**: High-contrast, tactile rocker switch for toggling between **White Mode** and **Dark Mode** with `localStorage` state retention.
- **Deep-Dive Case Study Drawer & Lightbox**: Slide-out technical drawer detailing project problem spaces, CAD engineering, CMF specifications, and a full-screen image lightbox modal.

## 5. Technology Stack

- **Markup**: HTML5 (Semantic, accessible with ARIA dialogs and roles)
- **Styling**: Modular CSS3 (Custom design tokens at `:root`, responsive grid/flexbox, zero framework dependencies)
- **Interactive 3D Engine**: [Three.js](https://threejs.org/) (r128) WebGL canvas for real-time parametric CAD inspection
- **Typography**: [Google Fonts](https://fonts.google.com/) (*Space Grotesk*, *Plus Jakarta Sans*, *JetBrains Mono*)
- **Background Animations**: HTML5 Canvas parametric spline engine + pure CSS GPU-accelerated floating ambient studio lights

## 6. How to Run Locally

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/<your-username>/industrial-design-portfolio.git
   cd industrial-design-portfolio
   ```

2. **Open in Browser**:
   - Simply double-click `index.html` to launch in any modern web browser.
   - Alternatively, serve locally using Python or Node:
     ```bash
     # Python 3
     python -m http.server 8080
     
     # Node (via npx serve)
     npx serve .
     ```
   - Navigate to `http://localhost:8080` to interact with the 3D CAD viewport, background animations, and case study drawers.

## 7. How to Customize Styles Later

All design tokens are organized right at the top of [`css/style.css`](css/style.css):

```css
:root {
  /* Atelier Museum White Theme */
  --bg-primary: #fbf9f4;        /* Main paper background */
  --bg-secondary: #f1ede3;      /* Secondary surface / track */
  --bg-surface: #ffffff;        /* Pure card surfaces */
  
  /* Industrial Accent Colors */
  --accent-blue: #185adb;       /* Technical cobalt accent */
  --accent-lime: #d6f830;       /* Highlighter volt accent */
  --accent-orange: #ff5722;     /* Safety cadmium / internship accent */
  
  /* Typography */
  --font-display: 'Plus Jakarta Sans', sans-serif;
  --font-body: 'Plus Jakarta Sans', sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

Modifying any of these tokens will automatically update colors, typography, and card borders across the entire portfolio.
